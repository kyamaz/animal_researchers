# animal_researchers

動物の研究者たちが研究室で交わす会話を通して、量子コンピュータや量子情報を学ぶ、スクロール型のスライドです。

公開ページ：https://kyamaz.github.io/animal_researchers/

## このリポジトリについて
- 公開用のリポジトリです。中身はビルドしたファイルだけで、制作用のリポジトリから同期しています。直接は編集しません。
- 更新は draft ブランチに push し、PR で main にマージします。GitHub Pages は main から配信します。
- `.nojekyll` は、`_astro/` フォルダを配信するために必要です（消さないでください）。
